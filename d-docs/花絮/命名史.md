# 命名史：拉挽乐 / Le Valet

状态：**历史记录，不构成技术约束。**

## 结果

```text
旧代号      delta-agent
中文名      拉挽乐
法语名      Le Valet
简称        V
```

最终选择：

> **拉挽乐 / Le Valet**

## 中文名：为什么叫“拉挽乐”

项目本质是一个 Agent harness。

`harness` 可以理解为套具、牵引框架：把模型、工具、任务和执行流程拉到一起，让它们协同完成工作。因此“拉”“挽”直接对应了项目的功能隐喻。

但只叫“拉挽”太正经，于是加入了第二层含义：

```text
拉挽乐
  │
  ├─ 字面：拉 + 挽 → harness / 牵引 / 协同
  │
  └─ 谐音：拉完了 → “这东西做得拉完了”
                  → 项目翻车时成立
                  → 项目做完时也成立
```

“乐”负责把这个自嘲收回来：拉完了，也乐。

所以中文名同时保留三层信息：

| 层 | 含义 |
|---|---|
| 功能 | harness 把组件、任务、流程拉到一起 |
| 谐音 | “拉完了”，预先自黑项目可能做烂 |
| 情绪 | “乐”，做成做烂都先留一个玩笑 |

这不是产品功能定义，只是项目自己的内部梗。

## 法语名：为什么不用直译

中文名确定后，没有继续追求英文直译。

原因很简单：

```text
直译 harness / traction / connector
        ↓
语义明确，但名字感弱

生造音译 Lawanle
        ↓
声音接近，但不像自然存在的名字
```

因此改成寻找一个自然的法语品牌名，要求是：

1. 使用 `Le + 法语名词` 的结构；
2. 不要求严格音译；
3. 整体节奏能留下“拉挽乐”的影子；
4. 词本身最好能和 Agent / harness 建立某种语义联系；
5. 看起来像真正的名字，而不是拼音改造。

## 候选过程

讨论过的主要候选：

| 候选 | 当时看中的点 | 放弃原因 |
|---|---|---|
| `Le Relais` | 传递、交棒、中继；很贴近 model ↔ tool 的 handoff | 发音虽顺，但和“拉挽乐”的节奏仍差一截；词也较常见 |
| `Le Liant` | “把不同东西结合起来”的语义很贴 harness | 语义强，声音弱 |
| `Le Raccord` | 连接、接口、工程感强 | 太像工业连接件 |
| `Le Maillon` | 链条中的一环 / link | 更像系统中的一个节点，不像统筹整个执行循环的 harness |
| `Le Rouage` | 齿轮、复杂系统中的运作部件 | 机械隐喻好，但角色偏“零件” |
| `Le Treuil` | 绞盘、牵引；和“拉/挽”字面义接近 | 发音不够直观 |
| `Le Harnais` | 法语里的 harness，字面最直接 | 太直译，也容易让人想到马具 |
| `Le Valet` | 发音节奏最接近；valet 又有侍从、服务者含义 | “侍从”语义带从属性，但对 Agent 反而可以成立 |

## 最终为什么是 Le Valet

真正决定结果的是声音。

```text
拉 · 挽 · 乐
Le · Va · let
```

`Le Valet` 不需要逐字对应中文，却保留了相似的三拍节奏。相比其他候选，它更像“拉挽乐”在另一种语言里的影子。

同时，`valet` 的“侍从 / 服务者”含义和 Agent 的角色存在自然联系：

```text
用户
 │
 ▼
Le Valet
 │
 ├─ 调模型
 ├─ 调工具
 └─ 把任务办完
```

因此最终取舍不是“哪个法语词最准确地翻译 harness”，而是：

> **哪个自然存在的法语名字，同时最像“拉挽乐”，又能给 Agent 一个说得通的角色隐喻。**

答案是 `Le Valet`。

   ▼
